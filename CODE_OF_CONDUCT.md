# Code of conduct

Project participants are expected to communicate respectfully, critique methods
rather than people, protect confidential health information, disclose conflicts
of interest, and report scientific or software errors promptly. Harassment,
discrimination, privacy violations, fabricated results, and attempts to bypass
the leakage safeguards are not acceptable.

Concerns should be reported privately to the repository maintainers. Until a
public maintainer contact is listed, use GitHub's private vulnerability-reporting
channel rather than posting confidential information in an issue.
